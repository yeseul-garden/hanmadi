내 Google 시트에 답변을 모아요

시트 주소만으로는 Hanmadi가 답변을 기록할 수 없습니다. Google에서 제공하는 연결 도구를 본인 계정에 설치하고, 이 시트에 답변을 쓸 권한을 한 번 승인해주세요.

연결 도구의 이름은 Google Apps Script입니다. 아래에서 준비한 코드 하나를 복사해 붙여 넣으면 됩니다. 직접 코드를 작성할 필요는 없습니다.

1. 답변을 모을 시트를 알려주세요

시트는 본인 계정에 보관됩니다. 참가자에게 시트 편집 권한을 줄 필요는 없습니다.

아직 시트가 없나요?

빈 시트를 만들면 필요한 열은 연결할 때 자동으로 준비됩니다. 미리 형식을 보고 싶다면 템플릿을 사용하세요.

빈 Google 시트 만들기
부스 인증·저장 위치 (선택)

기존 봇이 사용하는 ID를 이름과 별도로 받습니다. 이 ID는 공개 화면에 표시하지 않습니다.

설문을 여러 개 운영할 때만 확인하세요

설문마다 저장할 탭 이름을 다르게 지정하고 연결 코드를 준비합니다. 설문이 하나라면 기본값 hanmadi를 그대로 사용하세요.

2. Google에 연결 도구 설치하기

방금 만든 코드를 Google 화면에 그대로 붙여 넣으세요. 파일을 여러 개 만들 필요는 없습니다.

Google 연결 화면 열기
  1. Google 화면에서 ‘새 프로젝트’를 누르세요. 처음 보이는 기본 코드 전체를 지우고 복사한 코드를 붙여 넣은 뒤 저장합니다.
  2. 상단 함수 선택 메뉴에서 ‘initializeHanmadi’를 선택하고 ‘실행’을 누르세요. Google이 권한을 물으면, 이 시트에 답변을 기록하도록 승인합니다.
  3. 오른쪽 위 ‘배포 → 새 배포’를 누르세요. 유형은 ‘웹 앱’, 실행 사용자는 ‘나’, 액세스 권한은 ‘모든 사용자’를 선택합니다.
  4. 배포 후 나오는 ‘웹 앱 URL’을 복사하세요. 아래 단계에 붙여 넣으면 연결이 끝납니다.

‘모든 사용자’는 참가자가 Google 로그인 없이 답변을 보낼 수 있게 하는 설정입니다. 시트 자체를 공개하는 설정은 아닙니다.

연결 코드 보기·파일로 보관하기

이 코드에는 내 시트 정보가 들어 있습니다. GitHub에는 올리지 마세요. 질문이나 저장할 탭을 바꾸면 코드를 다시 만들어 설치해주세요.

3. 연결하고 답변을 보내보세요

주소 끝이 /exec인지 확인해주세요. Google 비밀번호는 여기에 입력하지 않습니다.

연결 후, 접수를 시작하거나 마감하려면

Google 시트에 자동으로 생긴 ‘hanmadi_설정’ 탭을 여세요. ‘답변 받기’를 체크하면 접수 중, 체크를 해제하면 마감됩니다. 다른 탭 이름을 골랐다면 그 이름 뒤에 ‘_설정’이 붙습니다.

Sheets 모드는 답변을 시트에 기록합니다. Hanmadi 화면의 ON/OFF와 타이머는 다른 휴대폰에 전달되지 않습니다. 공개 화면과 타이머까지 함께 공유하려면 Supabase 모드를 사용하세요.

Supabase는 여러 기기의 답변을 모아 같은 행사 화면에 보여주는 저장 서비스입니다. 운영자로 로그인하면 답변과 공감, 남은 시간을 함께 공유할 수 있습니다.

  1. Supabase SQL Editor에서 설치 SQL을 실행하세요.
  2. Authentication에서 Anonymous Sign-Ins를 켜고, Users에서 운영자 이메일 계정을 만드세요.
  3. 프로젝트 URL과 Publishable key를 입력하고 운영자 계정으로 로그인하세요.
  4. 새 행사를 만들거나 기존 행사를 선택한 뒤 QR을 공유하세요.

공개용 키만 사용하세요. Secret key와 데이터베이스 비밀번호는 입력하지 않습니다.

다시 방문하면 같은 URL·공개용 키로 연결한 뒤 기존 행사를 선택할 수 있습니다. 비밀번호는 Hanmadi 코드나 공유 링크에 저장하지 않습니다.
