# 참가자 링크를 선택해서 짧게 만들기

별도 Cloudflare 배포나 공유 링크 저장소 설정이 필요하지 않습니다. 처음 연결한 Supabase 또는 Google Sheets 정보로 원래 공유 주소와 QR을 바로 만듭니다.

1. 운영 화면에서 **참가자 QR·링크**를 누릅니다.
2. 창 왼쪽 아래에서 **URL 단축**을 선택합니다.
3. 성공하면 표시 주소와 QR이 함께 짧은 주소로 바뀝니다. **링크 복사** 또는 **QR 이미지 저장**을 사용하세요.
4. 선택을 해제하면 원래 주소와 QR로 돌아갑니다. 단축이 실패해도 원래 주소를 그대로 쓸 수 있습니다.

## 외부 서비스 사용

선택할 때만 공개 참가자 주소를 is.gd로 보냅니다. 별도 가입이나 API 키는 필요하지 않습니다. 원래 주소에는 Supabase 프로젝트 주소·공개 키·설문 코드 또는 Google Apps Script 공개 배포 주소가 포함될 수 있습니다. 비밀번호, 로그인 토큰, Google 운영자 연결 키는 공유 주소에 넣지 않습니다. 사용자의 답변은 원래 연결한 저장소에 보관합니다.

단축 서비스가 정한 한도나 이용 제한이 적용됩니다. 서비스 장애에 대비해 원래 링크도 사용할 수 있습니다. 같은 창에서의 재시도는 원래 주소별 메모리 캐시를 사용합니다. 창을 다시 열 때 URL 단축은 기본적으로 해제됩니다. 짧은 주소는 is.gd 도메인을 사용하며, Hanmadi 자체 도메인의 20자리 주소를 새로 발급하지 않습니다.

참고: https://is.gd/apishorteningreference.php

## 창을 닫았다 다시 운영하기

Supabase에 저장된 설문과 답변은 브라우저 창을 닫아도 남습니다. 같은 프로젝트 주소와 공개 키로 운영자 로그인한 뒤 **기존 설문**을 선택하세요. 또는 저장한 **운영자 링크**를 열고 인증하면 같은 설문을 다시 운영할 수 있습니다. 운영자 링크 자체는 관리 권한을 부여하지 않습니다. 로그인한 계정이 소유한 설문만 열립니다.

Google Sheets의 답변은 시트에 남습니다. 운영자 링크로 다시 접속할 때는 해당 Apps Script의 운영자 연결 키가 필요합니다. 연결하지 않은 체험 모드의 답변은 새로고침·창 종료 후 유지되지 않을 수 있습니다.

기존 20자리/10자리 공유 주소는 이전 설정이 배포되어 있다면 읽는 호환성을 유지합니다. 새 사용자는 그 설정을 설치하거나 JSON 파일을 업로드할 필요가 없습니다.
