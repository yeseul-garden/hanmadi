# 로고·제목·답변·타이머를 모든 화면에 표시하기

## 이번 업데이트

- 화면 제목은 최대 40자입니다. 운영 화면의 **화면 꾸미기 → 화면 제목**에서 바꿉니다. 비워두면 `hanmadi`입니다. 모바일에서는 작은 글씨로 두 줄까지 표시합니다.
- Google Sheets 연결 코드 v2는 약 15초마다 다른 참가자의 답변과 로고·제목·접수 상태·타이머 설정을 불러옵니다. 타이머 숫자는 각 화면에서 계속 줄어듭니다. Google 서비스가 느리면 반영이 더 늦어질 수 있습니다.
- 운영자가 숨기기·고정·완료로 표시한 답변도 공유합니다. 참가자 ID, 기기 ID, 테스트 기록은 공개 목록에 보내지 않습니다.
- 발표 화면에서도 목록형·카드형·우주형과 밝은/어두운 화면을 바꿀 수 있습니다. 발표 화면에서 바꾼 보기는 해당 화면에만 적용됩니다. 참가자는 운영자가 정한 보기를 따릅니다.
- Sheets의 공감 수 공유는 이번 버전에 포함하지 않습니다. 공감까지 여러 기기에서 공유하려면 Supabase를 사용하세요.

## 기존 Google 연결을 업데이트하는 순서

사이트 파일을 바꾸는 것만으로는 이미 배포한 Google 연결 도구가 바뀌지 않습니다. 기존 응답 시트와 Apps Script 프로젝트를 그대로 사용하세요.

1. 최신 사이트에서 설문 준비 또는 운영 화면의 **저장할 곳 선택·연결하기**를 엽니다.
2. 기존 `/exec` 주소를 입력하고 **기존 연결 정보 불러오기**를 누릅니다. 기존 설문 코드·질문을 유지하기 위한 단계입니다.
3. 원래 Google 시트 주소와 같은 답변 탭 이름을 입력합니다. **연결 코드 만들기 → 연결 코드 복사**를 누릅니다. 로고·제목을 새로 지정했다면 이 단계 전에 설정하세요.
4. 같은 Apps Script 프로젝트의 코드를 새 코드 전체로 교체하고 저장합니다. **initializeHanmadi**를 실행합니다. 답변 행은 지우지 않습니다.
5. **배포 → 배포 관리 → 연필 → 새 버전 → 배포**로 기존 배포를 업데이트합니다. 새 배포를 따로 만들면 주소가 달라집니다.
6. Hanmadi로 돌아와 같은 `/exec` 주소로 **연결하고 테스트하기 → 이 저장 방식으로 계속**을 누릅니다. 운영자 연결 키는 코드를 만든 브라우저에 자동 보관합니다. 다른 브라우저에서 운영하려면 같은 키를 따로 보관해 입력하세요. 이 키는 참가자에게 공유하거나 GitHub에 올리지 마세요.
7. 기존 화면에만 있던 로고·제목·시간 설정은 한 번 다시 적용해주세요. 휴대폰 두 대와 발표 창을 열어 답변·로고·남은 시간이 함께 보이는지 확인합니다.

설정 탭의 **답변 받기** 체크도 계속 사용할 수 있습니다. 설정 탭의 8행 아래에는 화면 설정이 나뉘어 저장되므로 직접 편집하지 마세요. 연결을 끊거나 브라우저를 닫아도 Google 시트에 저장된 답변은 남습니다.

## 이전 버전의 짧은 공유 주소

아래는 구형 10자리 정적 매핑 방식입니다. 새 주소 생성은 [20자리 공통 규칙](uniform-share-urls.md)을 사용합니다.

GitHub Pages에서는 다음처럼 `#` 뒤의 경로를 사용합니다. 새로고침해도 404가 나지 않습니다.

- 참가자: `https://yeseul-garden.github.io/hanmadi/#/r7m4k2v9qa/participant-form`
- 발표: `https://yeseul-garden.github.io/hanmadi/#/r7m4k2v9qa/result`

위 두 링크는 전달받은 기존 `emwxlrrio` 설문과 배포 주소에 연결됩니다. 기존 긴 링크도 계속 지원합니다. `result`가 올바른 철자이며, 입력 실수를 위해 `reseult`도 읽습니다.

새 설문의 경우 **공유 주소 설정 → 짧은 링크 설정 내보내기**에서 받은 `event-links.js`를 GitHub의 같은 파일과 교체해 배포합니다. 기존 항목을 유지하세요. 파일을 배포하고 페이지를 다시 연 뒤 QR을 생성하면 짧은 주소를 사용합니다. 등록 전에는 작동하는 기존 긴 주소를 사용합니다. 이 파일에는 공개 설문 코드와 연결 주소만 들어 있으며 운영자 키와 응답은 포함되지 않습니다.

## 확인한 범위

로컬 검사에서 세 화면의 상태 공유, 로고 분할 저장, 공개 응답의 개인정보 제외, 운영자 키 검사, 타이머 마감, 중복 제출 복구, 구형/신형 링크 구분을 확인했습니다. 실제 Google 계정의 코드 교체와 여러 휴대폰 테스트는 별도로 필요합니다. Apps Script 할당량 때문에 500명이 동시에 이용할 수 있다고 보장하지 않습니다.

참고: [Apps Script 할당량](https://developers.google.com/apps-script/guides/services/quotas), [Cache 서비스](https://developers.google.com/apps-script/reference/cache/cache), [GitHub Pages의 404 처리](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-custom-404-page-for-your-github-pages-site).
