# Google 시트에 처음 연결하기

시트 주소는 “어디에 답변을 모을지”를 알려줍니다. 주소만으로 Hanmadi가 내 시트에 글을 쓸 수는 없습니다. Google이 제공하는 연결 도구를 본인 계정에 설치하고, 답변을 기록할 권한을 승인해야 합니다. 그 도구의 이름이 **Google Apps Script**입니다.

Hanmadi가 연결 코드를 준비합니다. 사용자는 코드를 직접 작성하지 않고 복사·붙여 넣기만 합니다. Google의 권한 승인과 웹 앱 배포 단계는 필요합니다.

## 1. 내 시트 주소 입력

최신 업데이트를 GitHub Pages에 배포하고 **내 설문 만들기 → 연결과 확인 → 저장할 곳 선택·연결하기 → Google 시트에 답변 모으기**을 선택하세요.

열어둔 Google 시트의 주소를 붙여 넣고 **연결 코드 만들기**를 누릅니다. 빈 시트도 사용할 수 있으며, 필요한 열은 연결할 때 자동으로 준비됩니다. 기본 답변 탭은 `hanmadi`입니다.

부스 인증 봇과 연결한다면 **부스 인증·저장 위치 (선택)**을 펼쳐 **부스 인증용 참가자 ID도 받기**를 켭니다. 참가자가 입력할 ID는 기존 봇이 사용하는 식별값과 같아야 합니다. 표시 이름과는 별개이며 참가자 화면 미리보기에는 표시하지 않습니다.

## 2. Google에서 연결 도구 설치

앱의 **연결 코드 복사 → Google 연결 화면 열기**를 누릅니다.

1. Google 화면에서 **새 프로젝트**를 만듭니다. 처음 보이는 기본 코드 전체를 지우고, 복사한 코드 전체를 붙여 넣은 뒤 저장하세요. 파일은 하나면 됩니다. 별도의 HTML 파일은 만들지 않습니다.
2. 상단 함수 선택 메뉴에서 **initializeHanmadi**를 고르고 **실행**을 누릅니다. 연결할 시트에 답변을 기록하도록 Google 권한을 승인하세요.
3. 오른쪽 위 **배포 → 새 배포**를 누릅니다. 유형은 **웹 앱**, 실행 사용자는 **나**, 액세스 권한은 **모든 사용자**를 선택합니다.
4. 배포가 끝나면 나오는 **웹 앱 URL**을 복사합니다. 주소 끝은 `/exec`입니다.

**‘모든 사용자’는 참가자가 Google 로그인 없이 답변을 보낼 수 있게 하는 설정입니다. 시트 자체를 공개하거나 참가자에게 편집 권한을 주는 설정은 아닙니다.** 회사 Google 계정은 조직 정책에 따라 이 배포를 제한할 수 있습니다.

연결 코드를 파일로 보관하고 싶다면 **연결 코드 보기·파일로 보관하기**에서 `Code.gs`를 저장할 수 있습니다. 내 시트 설정이 들어 있으므로 GitHub에 올리지 마세요. Google 비밀번호를 Hanmadi에 입력할 필요는 없습니다.

## 3. 연결하고 테스트

Hanmadi에 돌아와 **Google에서 받은 웹 앱 URL**에 주소를 붙여 넣고 **연결하고 테스트하기**를 누릅니다. 연결 확인과 테스트 기록 저장을 한 번에 진행합니다.

시트에 테스트 기록 한 줄이 생기면 **이 저장 방식으로 계속 → 진행 화면 열기**를 누르세요. 참가자 QR을 휴대폰 두 대에서 열어 각각 답변을 제출하고, 시트에 두 기록이 들어오는지 확인합니다.

테스트 행은 `activity_status=test`, 실제 답변은 `submitted`입니다. 봇은 실제 답변만 인증해야 합니다. 실제 참가자 ID로 제출한 뒤 기존 봇의 인증 메시지까지 확인하세요.

## 접수를 마감하려면

시트에 자동으로 생긴 **`hanmadi_설정` 탭 → ‘답변 받기’ 체크 해제**만 하면 됩니다. 다시 체크하면 재개됩니다. 답변 탭 이름이 다르면 그 이름 뒤에 `_설정`이 붙습니다.

한글 열 9개가 있는 기존 `hanmadi` 탭도 지원합니다. 초기 설정 시 내부 관리용 열 3개와 설정 탭이 추가됩니다. 이미 받은 답변은 체크를 꺼도 유지되고, 마감 후 새 답변만 거절됩니다.

Sheets v2는 여러 휴대폰의 답변과 화면 설정·타이머를 약 15초마다 공유합니다. 운영자 연결 키가 있는 운영 화면에서 접수를 제어할 수 있습니다. 공감 공유는 Supabase를 사용하세요. 기존 연결은 [업데이트 안내](shared-screens-update.md)를 먼저 확인하세요.

질문이나 저장할 탭을 바꿨다면 연결 코드를 다시 준비하세요. 이미 배포한 Google 프로젝트의 코드를 바꿀 때는 **배포 관리 → 수정 → 새 버전**으로 반영해야 합니다.

더 자세한 데이터 형식과 한도는 [Google Sheets 연결 안내](google-sheets.md)를 참고하세요. 실제 Google 설치와 휴대폰 테스트는 본인 계정에서 확인해야 합니다.

연결 코드 준비에 필요한 파일은 최신 Hanmadi 화면 안에 포함됩니다. 별도 설치 파일 주소를 가져오지 않아도 코드를 만들 수 있습니다. 실제 시트 기록에는 Google 연결 도구 설치가 필요합니다.

## 자주 만나는 Google 화면

‘Google hasn’t verified this app’ 안내는 본인이 만든 Apps Script가 Google 검증을 받지 않아 표시될 수 있습니다. 표시된 개발자 이메일과 프로젝트가 본인 것이고, 직접 준비한 Hanmadi 코드를 붙여 넣은 경우에만 Advanced의 진행 링크를 선택하고 요청된 Sheets 권한을 확인하세요. 다른 사람의 알 수 없는 프로젝트에는 권한을 주지 마세요.

웹 앱 주소를 직접 열었을 때 **‘다음 스크립트 함수(doGet)를 찾을 수 없습니다’**가 보이면, 편집기에 `function doGet(e)`를 포함한 코드 전체가 있는지 확인하세요. 저장한 뒤 **배포 → 배포 관리 → 연필 아이콘 → 새 버전 → 배포**로 반영해야 합니다. 코드 저장만으로 기존 배포 버전은 갱신되지 않습니다.

대화 안의 미리보기는 외부 연결을 테스트하는 장소가 아닙니다. 배포된 GitHub Pages 사이트를 직접 열어서 연결하세요.
