# Hanmadi 화면 문구 원칙

처음 쓰는 사람이 도움말을 따로 읽지 않아도 다음 행동을 고를 수 있도록 씁니다.

## 기본 문체

- 설명과 오류 안내는 ‘해주세요’, 결과 안내는 ‘했습니다’로 일관되게 씁니다. 참가자의 잘못으로 단정하지 않습니다.
- 버튼에는 누르면 일어나는 행동을 씁니다. ‘확인’만 쓰는 대신 ‘연결하고 테스트하기’, ‘코드 전체 선택’처럼 대상을 밝힙니다.
- 제품 용어는 쉬운 말로 통일합니다. ‘키컬러’는 ‘대표 색상’, ‘정렬’은 ‘표시 순서’로 씁니다.
- 설정 이름과 안내문에서 같은 단어를 씁니다. 버튼 이름을 안내에 인용할 때도 실제 화면과 맞춥니다.

## 상황별 안내

| 상황 | 쓰는 순서 | 예시 |
| --- | --- | --- |
| 처음 연결 | 할 일 → 필요한 이유 → 다음 행동 | 시트 주소를 입력해주세요. 답변을 기록할 곳을 정합니다. |
| 권한 요청 | 필요한 이유 → 요청할 권한 | 답변을 시트에 기록하려면 Google의 승인이 필요합니다. |
| 입력 오류 | 확인할 항목 → 수정 방법 | 시트 주소를 확인해주세요. 시트를 연 뒤 주소 전체를 복사해 붙여 넣으세요. |
| 연결 실패 | 실패한 일 → 확인할 곳 | Google 연결 도구가 응답하지 않습니다. 연결 주소를 직접 열어 오류를 확인해주세요. |
| 복사 제한 | 가능한 다른 방법 | 코드 전체를 선택했습니다. 복사 단축키를 누르거나 길게 눌러 복사해주세요. |
| 완료 | 실제로 끝난 일 | 연결되었습니다. 시트에 테스트 기록 한 줄을 남겼습니다. |

원인을 확인하지 못했으면 권한이나 입력값이 틀렸다고 단정하지 않습니다. 코드를 선택한 상태를 ‘복사 완료’라고 표시하지 않습니다. Google Sheets의 기록과 Supabase의 화면 공유도 같은 기능으로 설명하지 않습니다.

## 기술 용어

Google 화면에서 찾아야 하는 이름은 유지하고 뜻을 설명합니다. Apps Script는 ‘Google에서 제공하는 연결 도구’, Publishable key는 ‘공개용 연결 키’로 안내합니다. 웹 앱, SQL Editor, Anonymous Sign-Ins처럼 외부 화면과 대조할 이름은 필요한 단계에서만 보여줍니다.

## 한영 지원

버튼과 안내는 한국어·영어를 함께 관리합니다. 운영자가 직접 입력한 행사명, 질문, 답변, 이름은 자동으로 번역하거나 고치지 않습니다. 화면 문구는 `src/ux-copy.json`, 연결 단계의 문구는 `src/sheets-beginner-i18n.json` 등에서 관리합니다.

## 읽기와 복사

연결 모달의 본문·버튼·입력칸은 같은 UI 글꼴을 씁니다. 한국어는 단어 단위로 줄을 바꾸고, 긴 주소나 코드는 넘칠 때 별도로 표시합니다. 연결 코드만 고정폭 글꼴로 표시하며, 글꼴·줄바꿈 표시와 실제 복사할 코드 내용은 분리합니다.

참고: [UX Writing Skill](https://github.com/content-designer/ux-writing-skill)의 목적성·간결성·자연스러움·명확성 원칙. 한국어 문구는 Hanmadi의 실제 기능과 사용자 흐름에 맞춰 작성했습니다.
